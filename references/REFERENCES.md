# NeoCrisálida — Visual Reference Guide

## Purpose

These references are evidence, not templates.

The goal is to understand NeoCrisálida's existing identity and combine it with selected design principles to create a completely new visual system.

The resulting website must feel like NeoCrisálida.

Not like a mixture of references.

---

# Priority hierarchy

Interpret the references in this order:

1. NeoCrisálida existing brand
2. Transformation journey
3. Dawn structural/storytelling principle
4. Softlight typography
5. Hero composition references
6. When We Love section composition

The brand and transformation concept take priority over external references.

# 2. CORE NARRATIVE — THE TRANSFORMATION JOURNEY

This is the strongest desired conceptual direction.

NeoCrisálida means transformation.

The page should explore the possibility that scrolling through the website feels like progressing through a transformation.

Not through literal storytelling text.

Through VISUAL EXPERIENCE.

The background may itself become a journey.

For example, the visual world may progress from:

contained
→ opening
→ movement
→ transition
→ emergence
→ space

Possible mechanisms:

- background states evolve;
- shapes transform;
- an abstract trace travels through sections;
- openings become larger;
- layers unfold;
- colors shift subtly;
- forms become less constrained;
- light increases;
- visual elements evolve from incomplete to complete;
- motion reinforces progression.

The butterfly can participate.

But:

DO NOT solve this by repeatedly placing butterfly icons.

DO NOT make it childish.

DO NOT make it mystical.

The transformation should preferably be felt before it is explained.

The exact solution is intentionally open.

Impeccable should find the strongest execution.

---

# 3. DAWN — STRUCTURAL STORYTELLING

File:

`global/dawn-structure.png`

Dawn is the strongest external structural reference.

The relevant lesson is NOT its exact page layout.

The relevant lesson is:

One visual idea can hold an entire website together.

The sun becomes part of the narrative and makes sections feel connected.

For NeoCrisálida:

Explore whether transformation can create the same level of structural coherence.

The website should feel like one continuous visual world rather than:

Hero +
Cards +
About +
Cards +
CTA

Do not copy Dawn.

Extract the principle.

# 5. HERO EXPLORATION

Files:

- hero/mental-health-hero.png
- hero/healthora-hero.png
- hero/psychiatrist-hero.png

These are HERO REFERENCES ONLY.

Do not use the rest of those websites as structural inspiration.

Explore at least three materially different hero priorities.

## A — Carmen

Carmen is the primary trust anchor.

The visitor immediately feels:

"There is a real person here."

## B — Message

The emotional proposition / typography becomes primary.

The visitor immediately feels:

"This is a place for things that are difficult to say."

## C — Transformation

The NeoCrisálida visual world itself becomes the main opening experience.

The visitor immediately feels:

"Something is changing / opening / emerging."

Carmen and the service must still remain understandable.

The three directions should belong to the SAME brand world.

They must not feel like three unrelated brands.

# Overall synthesis objective

The final experience should feel:

human +
warm +
safe +
professional +
editorial +
emotionally intelligent +
distinctive +
transformative

The key difference from a conventional psychology website should be that NeoCrisálida feels like a coherent visual journey.

The journey must remain subtle enough that usability and Carmen's credibility are never sacrificed.

# Anti-copy rule

Never copy:

- exact layouts;
- colors;
- fonts;
- animations;
- brand symbols;
- another site's components;
- another site's copy.

References demonstrate possibilities.

They are not implementation instructions.
